# NForge

NForge is a simple AI-assisted research paper management application designed to help users organize research papers and use AI to understand and analyze them.

## Features
- Upload and manage research papers (PDF)
- AI-generated paper summarization
- Ask questions about uploaded papers
- Basic research gap identification

## Technology Stack
- Frontend: React (Vite), React Router, Axios, CSS/Bootstrap
- Backend: Django, Django REST Framework, PostgreSQL
- AI: PyMuPDF (PDF extraction), Sentence Transformers (semantic search), LLM (generation)
